Implement `IsGitRepo(dir string) bool`:
- Call `gogit.PlainOpenWithOptions(dir, &gogit.PlainOpenOptions{DetectDotGit: true})`
- Return `true` if no error, `false` if `err == gogit.ErrRepositoryNotExists` or any other error

Implement `GetFileStatuses(repoRoot string, relPaths []string) (map[string]GitStatus, error)`:
- `gogit.PlainOpenWithOptions(repoRoot, &gogit.PlainOpenOptions{DetectDotGit: true})`
- If `err == gogit.ErrRepositoryNotExists`, return empty map, nil error (D-12)
- `wt, err := repo.Worktree()`
- `status, err := wt.Status()`
- For each relPath: `fs := status.File(relPath)`
  - Use `filepath.ToSlash(relPath)` before lookup (Pitfall 6: go-git uses forward slashes)
  - Switch on `fs.Worktree` and `fs.Staging`:
    - `gogit.Modified` on either -> `GitStatusModified`
    - `gogit.Added` on either -> `GitStatusAdded`
    - `gogit.Untracked` on Worktree -> `GitStatusUntracked`
    - Default -> `GitStatusClean`
- Return the result map

Implement `GetFileHistory(repoRoot, relPath string, limit int) ([]CommitEntry, error)`:
- `gogit.PlainOpenWithOptions(repoRoot, &gogit.PlainOpenOptions{DetectDotGit: true})`
- If err, return nil, err
- `slashPath := filepath.ToSlash(relPath)` (Pitfall 6)
- `iter, err := repo.Log(&gogit.LogOptions{FileName: &slashPath})`
- `iter.ForEach(func(c *object.Commit) error { ... })`
  - If `limit > 0 && len(entries) >= limit`, return `storer.ErrStop`
  - Extract subject = first line of `c.Message` (split on '\n')
  - Build `CommitEntry{ShortHash: c.Hash.String()[:7], RelDate: relativeTime(c.Author.When), Author: c.Author.Name, Subject: subject}`
- Return entries, err

Implement `relativeTime(t time.Time) string`:
```go
func relativeTime(t time.Time) string {
    d := time.Since(t)
    switch {
    case d < time.Minute:
        return "just now"
    case d < time.Hour:
        n := int(d.Minutes())
        if n == 1 { return "1 minute ago" }
        return fmt.Sprintf("%d minutes ago", n)
    case d < 24*time.Hour:
        n := int(d.Hours())
        if n == 1 { return "1 hour ago" }
        return fmt.Sprintf("%d hours ago", n)
    case d < 30*24*time.Hour:
        n := int(d.Hours() / 24)
        if n == 1 { return "1 day ago" }
        return fmt.Sprintf("%d days ago", n)
    case d < 365*24*time.Hour:
        n := int(d.Hours() / (24 * 30))
        if n == 1 { return "1 month ago" }
        return fmt.Sprintf("%d months ago", n)
    default:
        n := int(d.Hours() / (24 * 365))
        if n == 1 { return "1 year ago" }
        return fmt.Sprintf("%d years ago", n)
    }
}
```
