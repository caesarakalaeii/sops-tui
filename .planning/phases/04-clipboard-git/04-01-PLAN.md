Add helper function `clipboardTimeout()`:
```go
// clipboardTimeout returns the clipboard auto-clear duration.
// Default 30s, overridden by SOPS_TUI_CLIPBOARD_TIMEOUT env var (D-05).
func clipboardTimeout() time.Duration {
    if s := os.Getenv("SOPS_TUI_CLIPBOARD_TIMEOUT"); s != "" {
        if n, err := strconv.Atoi(s); err == nil && n > 0 {
            return time.Duration(n) * time.Second
        }
    }
    return 30 * time.Second
}
```

Add clipboard copy method on AppModel:
```go
func (m AppModel) copyToClipboard(value string) (AppModel, tea.Cmd) {
    if clipboard.Unsupported {
        var statusCmd tea.Cmd
        m.status, statusCmd = m.status.Flash("Clipboard not available (install xclip or wl-clipboard)")
        return m, statusCmd
    }
    if err := clipboard.WriteAll(value); err != nil {
        var statusCmd tea.Cmd
        m.status, statusCmd = m.status.Flash("Clipboard error: " + err.Error())
        return m, statusCmd
    }
    m.clipboardGen++
    gen := m.clipboardGen
    m.clipboardHot = true
    m.status.SetClipboardHot(true)
    var statusCmd tea.Cmd
    m.status, statusCmd = m.status.Flash("Copied (clears in 30s)")
    timeout := clipboardTimeout()
    clearCmd := tea.Tick(timeout, func(_ time.Time) tea.Msg {
        return ClipboardClearMsg{Gen: gen}
    })
    return m, tea.Batch(statusCmd, clearCmd)
}
```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| clipboard -> OS | Decrypted secret crosses from process memory to OS clipboard (visible to all processes on X11/Wayland) |
| signal -> process | OS signals (SIGINT/SIGTERM) trigger cleanup before exit |
| env var -> timeout | SOPS_TUI_CLIPBOARD_TIMEOUT parsed from environment |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Information Disclosure | clipboard.WriteAll | mitigate | 30s auto-clear via tea.Tick + generation counter (D-05, D-06); clear on exit via defer + signal handler (D-07) |
| T-04-02 | Information Disclosure | clipboard on SIGKILL/OOM | accept | SIGKILL cannot be intercepted by any program; documented as known limitation in RESEARCH.md |
| T-04-03 | Denial of Service | SOPS_TUI_CLIPBOARD_TIMEOUT | mitigate | strconv.Atoi with fallback to 30s on invalid input; n > 0 check prevents zero/negative timeout |
| T-04-04 | Information Disclosure | clipboard.Unsupported | mitigate | Check clipboard.Unsupported before attempting WriteAll; flash "Clipboard not available" to user (Pitfall 1) |
| T-04-05 | Tampering | stale ClipboardClearMsg | mitigate | Generation counter prevents old timer from clearing new clipboard content (D-06, Pitfall 2) |
</threat_model>
