| T-03-08 | Information Disclosure | editOldVal in DetailModel | mitigate | editOldVal cleared when editActive=false (Esc or Enter). Not persisted beyond edit session. |
| T-03-09 | Denial of Service | textinput CharLimit | mitigate | `textinput.CharLimit = 1000` prevents memory exhaustion from extremely long input |
</threat_model>
