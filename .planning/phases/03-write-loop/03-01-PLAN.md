```go
const SopsTimeout = 30 * time.Second

func DecryptKey(ctx context.Context, filePath, keyPath string) (string, error)
func DecryptFile(ctx context.Context, filePath string) ([]byte, error)
func SetKey(ctx context.Context, filePath, keyPath, newValue string) error
func EncryptFile(ctx context.Context, srcPath, destPath string) error
func dotPathToIndex(dotPath string) string  // unexported but tested via _test in same package
```

Implementation details:
- `DecryptKey`: runs `exec.CommandContext(ctx, "sops", "decrypt", "--extract", index, filePath)`. Captures stdout and stderr in separate `bytes.Buffer`. Returns `strings.TrimRight(stdout.String(), "\n")`. Error wraps stderr content.
- `DecryptFile`: runs `exec.CommandContext(ctx, "sops", "decrypt", filePath)`. Returns `stdout.Bytes()`. Error wraps stderr.
- `SetKey`: runs `exec.CommandContext(ctx, "sops", "set", "--value-stdin", filePath, index)`. Passes value via stdin using `json.Marshal(newValue)` for correct JSON encoding (Pitfall 1). Captures stderr only.
- `EncryptFile`: runs `exec.CommandContext(ctx, "sops", "encrypt", srcPath)`. Writes stdout to destPath. For $EDITOR flow (Plan 03).
- `dotPathToIndex`: splits on "." and wraps each part in `["part"]`. Uses `strings.Builder`.
- `IsArrayIndexedKeyPath(keyPath string) bool`: exported helper that returns true if keyPath contains array index notation (regex `\[\d+\]`). Used by detail.go `e`/`X` handlers to block edits on array-indexed keys (Open Question 1 resolution).

All functions use `exec.CommandContext` with caller-provided context (caller applies `context.WithTimeout(ctx, SopsTimeout)`).

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| TUI -> sops subprocess | Untrusted: key paths from YAML could contain shell metacharacters |
| sops subprocess -> age key | Trusted: SOPS handles key access; TUI never reads age private key |
| Decrypted values in memory | Sensitive: plaintext lives in TreeNode.DecryptedValue until cleared |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Information Disclosure | sops.SetKey | mitigate | Use `--value-stdin` exclusively; never pass secret as CLI arg. Verify in executor.go: `cmd.Stdin = bytes.NewReader(jsonVal)` |
| T-03-02 | Information Disclosure | TreeNode.DecryptedValue | mitigate | ClearAllRevealed() called on every Esc-to-file-list transition (D-04). Zero out DecryptedValue string. |
| T-03-03 | Tampering | dotPathToIndex | accept | Keys come from YAML parser (already sanitized). No user free-text input to key paths. sops binary handles its own argument validation. |
| T-03-04 | Denial of Service | sops subprocess | mitigate | All exec calls use context.WithTimeout(ctx, SopsTimeout=30s). Prevents hung sops process blocking the TUI. |
| T-03-05 | Tampering | crypto/rand | mitigate | All random generation uses crypto/rand, never math/rand. Verified by explicit import. |
</threat_model>
