**Decision:** The drift detector calls each sub-model's `Hints()` and compares it to `keys.HintsFromBindings(km.ShortHelp())` after applying the keymap's `HiddenFromMenu()` suppression. Real constructors are used per D-307 / 09-RESEARCH.md §"Risks 4".

**Visibility-aware comparison helper** (defined inline in the test file):
```go
// expectedHintsWithSuppression derives the expected MenuHint slice from a keymap,
// applying any HiddenFromMenu() override. Concrete-type-asserts known overriders
// to avoid exporting menuVisibilityOverrider from internal/keys.
func expectedHintsWithSuppression(km help.KeyMap) []keys.MenuHint {
    expected := keys.HintsFromBindings(km.ShortHelp())
    type overrider interface {
        HiddenFromMenu() []key.Binding
    }
    if ov, ok := km.(overrider); ok {
        for _, hidden := range ov.HiddenFromMenu() {
            for i := range expected {
                if expected[i].Mnemonic == hidden.Help().Key {
                    expected[i].Visible = false
                    break
                }
            }
        }
    }
    return expected
}
```

This avoids requiring Plan 1 to export `menuVisibilityOverrider` (Plan 1 left it unexported per the recommendation; the test re-declares the same shape locally — Go satisfies the interface structurally).

**Sub-tests structure** — one per dispatcher branch (13 total):

For sub-models with Hints() (8): construct via real constructor, call .Hints(), compare to `expectedHintsWithSuppression(keys.DefaultXxxKeyMap)`.

For stateless states routed by menuHints() switch (5): set `m.state = stateXxx` on a buildAppModel result, call `m.menuHints()`, compare to `expectedHintsWithSuppression(keys.DefaultXxxKeyMap)`. The search-active override is one additional sub-test using the same fallback pattern as TestMenuHints_StateFileList_SearchActive at hints_test.go:44-62.
