#### D-107: BFS reachability walker rewrite

**Current state — single-block walker** (lines 137-184, full text):
```go
func TestViewNoNewStyle(t *testing.T) {
	repoRoot := findRepoRoot(t)
	path := filepath.Join(repoRoot, "internal/app/model.go")
	fset := token.NewFileSet()
	f, err := parser.ParseFile(fset, path, nil, 0)
	require.NoError(t, err, "parse model.go")

	var viewBody *ast.BlockStmt
	for _, decl := range f.Decls {
		fd, ok := decl.(*ast.FuncDecl)
		if !ok || fd.Name.Name != "View" || fd.Recv == nil {
			continue
		}
		if !isAppModelReceiver(fd.Recv) {
			continue
		}
		viewBody = fd.Body
		break
	}
	require.NotNil(t, viewBody, "View() method on AppModel not found in model.go")

	var violations []string
	ast.Inspect(viewBody, func(n ast.Node) bool {
		ce, ok := n.(*ast.CallExpr)
		if !ok {
			return true
		}
		se, ok := ce.Fun.(*ast.SelectorExpr)
		if !ok {
			return true
		}
		ident, ok := se.X.(*ast.Ident)
		if !ok {
			return true
		}
		if ident.Name == "lipgloss" && se.Sel.Name == "NewStyle" {
			pos := fset.Position(ce.Pos())
			violations = append(violations,
				"model.go:"+strconv.Itoa(pos.Line)+":"+strconv.Itoa(pos.Column))
		}
		return true
	})
	if len(violations) > 0 {
		t.Fatalf("UI-15 violation: lipgloss.NewStyle() call(s) inside AppModel.View():\n  %s\n\n"+
			"Declare styles as package vars in internal/ui/styles.go instead.",
			strings.Join(violations, "\n  "))
	}
}
```
**Transformation — two-pass BFS:**
- **Pass 1:** Parse `internal/app/model.go` (and optionally every non-`_test.go` file in `internal/app/` for cross-file helpers). For each `*ast.FuncDecl`, build a name → set-of-called-names map by `ast.Inspect`-ing the body and collecting `*ast.CallExpr` selector/ident names. Scope: same-package names only. Receiver-method calls (`m.foo()`) record `foo` as the called name.
- **Pass 2:** Initialise `reachable := map[string]bool{"View": true}`. BFS-walk the call-edge map starting from `"View"`; mark every transitively-called function name. For each reachable function (including `View`), run the same `ast.Inspect` body walk that the current implementation runs, collecting `lipgloss.NewStyle()` violations.
- Constrain to **non-test files only** (`!strings.HasSuffix(filename, "_test.go")`) per CONTEXT specifics §AST walker false positives.
- Walker fix sketch is in REVIEW WR-01 lines 122-130 — copy that sketch verbatim as the structural template; flesh out the call-edge collection and BFS body.
- After D-109 lands (the 3 model.go NewStyle removals), the walker will report **zero** violations under `View` reachability.
