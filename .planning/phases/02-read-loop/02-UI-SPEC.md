# Phase 2 — UI Design Contract

> Visual and interaction contract for Phase 2: Read Loop.
> Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> This is a terminal TUI (Go + Bubble Tea / Charm ecosystem), not a web frontend.
> All sizing is in terminal cells, not CSS pixels. No shadcn, no web component library.

---

## Design System

| Property        | Value                                          |
|-----------------|------------------------------------------------|
| Tool            | none (terminal TUI — lipgloss v2 + bubbles v2) |

## Spacing Scale

Terminal cells (columns for horizontal, rows for vertical). All multiples of the base unit.

| Token      | Value       | Usage                                              |
|------------|-------------|----------------------------------------------------|
| SpaceXS    | 1 cell      | Icon gap, inline separator, badge padding          |
| SpaceSM    | 2 cells     | Compact horizontal padding (status bar sections)   |
| SpaceMD    | 4 cells     | Default element horizontal padding, pane content indent |
| SpaceLG    | 6 cells     | Section separation, border + content gap           |
| SpaceXL    | 8 cells     | Major layout margin                                |
| TreeIndent | 2 cells/level | YAML tree indentation per nesting level          |

Exceptions: Search input bar height is 1 row (single-line input, no padding rows).

Source: `internal/ui/styles.go` `SpaceXS`–`SpaceXL`, `TreeIndent` constants.

## Typography

Terminal TUI — no point sizes. All text is monospace terminal font. "Weight" maps to lipgloss Bold/Faint attributes.

| Role          | Attribute         | Foreground    | Usage                                          |
|---------------|-------------------|---------------|------------------------------------------------|
| Body          | normal (no attr)  | `#cdd6f4`     | File names, key names, overlay body text       |
| Dim / muted   | Faint             | `#cdd6f4`     | Masked values (`***`), item counts, secondary info |
| Active label  | Bold              | `#cdd6f4`     | Help section headers, status flash messages    |
| Muted label   | normal            | `#6c7086`     | Tree connectors, separators, breadcrumb `>`    |

No variable font sizes in terminal TUI — all cells are equal height. The distinction is color + bold/faint, not size.

Source: `internal/ui/styles.go` `DimText`, `HelpSectionHeader`, `ColorFg`, `ColorMuted`.

## Color

Catppuccin Mocha palette. Never use `lipgloss.AdaptiveColor` (confirmed hang, issue #1036).

| Role            | Hex         | Usage                                                               |
|-----------------|-------------|---------------------------------------------------------------------|
| Dominant (60%)  | `#1e1e2e`   | Terminal background fill (implicit — not painted by app)            |
| Secondary (30%) | `#313244`   | Status bar background, help overlay background, error box background, search bar background, metadata overlay background |
| Accent (10%)    | `#89b4fa`   | See accent reserved list below                                      |
| Success         | `#a6e3a1`   | Env indicator checkmark (sops/age/.sops.yaml available)             |
| Warning         | `#f9e2af`   | Env indicator warning (age key or .sops.yaml missing), `[plain]` badge |
| Error/Destructive | `#f38ba8` | Env indicator cross (sops binary missing), error box border, `[unencrypted]` badge |
| Muted           | `#6c7086`   | Tree connectors, separators, overlay borders, dim text              |
| Foreground      | `#cdd6f4`   | Default body text                                                   |

**Accent (`#89b4fa`) is reserved for exactly these elements:**
- Currently selected row highlight (foreground on `#313244` background)
- Active breadcrumb segment (last segment in status bar)
- Tree expand/collapse indicators (`[+]` / `[-]`)
- Fuzzy match character highlights (matched characters in filtered results)
- Help overlay key labels (12-cell fixed-width column)
- Search input cursor / active search input border

**Not accent:** unselected file names, key names, values, tree connectors, badges.

Source: `internal/ui/styles.go` — all color constants established in Phase 1.
New Phase 2 additions: `[unencrypted]` badge uses `ColorError`; `[plain]` badge uses `ColorWarning`; type hints `(str)`/`(int)`/`(bool)` use `ColorMuted`.

## Interaction Contracts

### File List View (stateFileList)

| Key     | Action                                      |
|---------|---------------------------------------------|
| j / ↓   | Move selection down                         |
| k / ↑   | Move selection up                           |
| g       | Jump to first item                          |
| G       | Jump to last item                           |
| ctrl-d  | Half-page down                              |
| ctrl-u  | Half-page up                               |
| l / Enter | Open detail view for selected file        |
| /       | Activate inline search filter (file names) |
| i       | Open metadata overlay for highlighted file  |
| ?       | Open help overlay                           |
| q       | Quit                                        |
| Esc     | Clear active search (if search active); otherwise no-op |

### Detail View (stateDetail)

| Key         | Action                                        |
|-------------|-----------------------------------------------|
| j / ↓       | Move cursor down                              |
| k / ↑       | Move cursor up                                |
| g           | Jump to first key                             |
| G           | Jump to last key                              |
| ctrl-d      | Half-page down                                |
| ctrl-u      | Half-page up                                  |
| l / Enter   | Expand selected group node                    |
| h / ←       | Collapse selected group node                  |
| /           | Activate inline search filter (key paths)     |
| i           | Open metadata overlay for current file        |
| Esc         | Clear active search (if search active); else return to file list |
| ?           | Open help overlay                             |
| q           | Quit                                          |

### Metadata Overlay (stateMetadata)

| Key   | Action                         |
|-------|--------------------------------|
| i     | Close overlay, return to prevState |
| Esc   | Close overlay, return to prevState |
| ?     | Open help overlay              |
| q     | Quit                           |
| j / ↓ | Scroll metadata content down  |
| k / ↑ | Scroll metadata content up    |

### Search Mode (modal within stateFileList or stateDetail)

Search is a mode flag on the active view model, not a separate `sessionState`. The search bar replaces the bottom row of the content area (above the status bar).

| Key      | Action                                         |
|----------|------------------------------------------------|
| any char | Append to filter string; re-filter in real time |
| Backspace | Remove last character; re-filter              |
| Esc      | Clear filter; restore full list; dismiss bar   |
| Enter    | Confirm selection on highlighted item; dismiss bar |

## Overlay Layout Contract

Both `HelpModel` and the new `MetadataModel` follow this full-screen layout:

```
┌─────────────────────────────────────────────────────────┐
│  {Title}                                                │
│                                                         │
│  {Content rows}                                         │
│  ...                                                    │
│                                                         │
│  Press i or Esc to close            [muted footer]      │
└─────────────────────────────────────────────────────────┘
```

- Border: `lipgloss.RoundedBorder()` in `ColorMuted`
- Background: `ColorSurface` (`#313244`)
- Padding: 1 row / `SpaceMD` (4 cells) horizontal — matches `HelpModel`
- Width: terminal width − 2 (border cells)
- Height: terminal height − 2 (border cells) − status bar height

## Metadata Overlay Content Contract

SOPS metadata fields rendered in the overlay (from `sops:` block; requirement DEC-04):

| Field          | Label          | Format                                      |
|----------------|----------------|---------------------------------------------|
| version        | version        | Raw string, e.g. `3.12.2`                   |
| lastmodified   | last modified  | ISO 8601 date string from SOPS envelope     |
| mac            | MAC            | Full hex string (shows integrity status)    |
| age recipients | recipients     | One per line: public key fingerprint        |
| encrypted_regex | enc regex     | Pattern string if present, else `(none)`    |
| unencrypted_regex | unc regex   | Pattern string if present, else `(none)`    |

Label column: 16 cells fixed width, foreground `ColorMuted`.
Value column: remaining width, foreground `ColorFg`.

## File List Item Rendering Contract

Each file item renders as one primary line:

```
{filename relative to repo root}   [unencrypted]   (if unencrypted)
```

- `[unencrypted]` badge: `BadgeUnencrypted` style (bold, `#f38ba8`)
- Badge appears right of filename, separated by 1 cell (`SpaceXS`)
- No badge for confirmed SOPS-encrypted files
- Selected item: `SelectedRow` style (accent foreground, surface background) spans full width
- Secondary description line (from `bubbles/list` `DefaultItem.Description`): absolute path in `DimText`

Source: decision D-02 from `02-CONTEXT.md`.

---

## Detail View Leaf Rendering Contract

Phase 2 upgrades the leaf node rendering from plain `***` to type-hinted display:

**Encrypted leaf** (has SOPS cipher envelope):
```
{key}: *** (str)
       *** (int)
       *** (bool)
```
- `***`: `DimText` (faint, `#cdd6f4`)
- ` (str)` / ` (int)` / ` (bool)`: `TypeHintStyle` (faint, `#6c7086`)

**Unencrypted leaf** (matched by `unencrypted_regex` or not in `encrypted_regex`):
```
{key}: {plaintext value}  [plain]
```
- `{plaintext value}`: normal foreground `#cdd6f4`
- `[plain]`: `BadgePlain` style (normal, `#f9e2af`)

Source: decisions D-04 and D-06 from `02-CONTEXT.md`.

## Unencrypted File Banner Contract

When drilling into a file that matches `.sops.yaml` path_regex but lacks the `sops:` marker (decision D-03), the detail view shows a banner as the first visible line before the key tree:

```
Not yet encrypted — matches .sops.yaml rules
```

- Style: `WarnLabel` (bold, `#f9e2af`)
- Separator row (1 blank line) between banner and tree content
- All values shown in plaintext (no masking needed)

---

## Search Bar Rendering Contract

The search bar is a single terminal row placed between the main content area and the status bar. It is visible only when search mode is active.

```
/ {filter text}{cursor}
```

- `/` prompt glyph: `ColorAccent` (`#89b4fa`)
- Filter text: `ColorFg` (`#cdd6f4`)
- Background: `ColorSurface` (`#313244`) spanning full terminal width
- Cursor: terminal default block cursor; no custom cursor rendering needed
- Height: 1 row; main content area shrinks by 1 row when search bar is visible

Fuzzy match highlighting in the list/tree above:
- Matched characters replaced with `SearchMatchStyle` (foreground `#89b4fa`)
- Non-matched characters keep normal foreground
- Source: decision D-12 from `02-CONTEXT.md`; `sahilm/fuzzy` provides matched char positions

## Status Bar Updates for Phase 2

The existing `StatusBarModel` requires these breadcrumb/count updates:

| Transition                     | Breadcrumb                        | Count             |
|--------------------------------|-----------------------------------|-------------------|
| App start (file list)          | `sops-tui > files`                | `{N} items`       |
| Enter detail view              | `sops-tui > files > {filename}`   | `{N} keys`        |
| Open metadata overlay          | `sops-tui > files > {filename} > metadata` | `—` (no count) |
| Return from metadata           | Restore previous breadcrumb       | Restore previous count |
| Search active (file list)      | Append `> search`                 | `{N} matches`     |
| Search active (detail)         | Append `> search`                 | `{N} matches`     |
| Search cleared                 | Restore previous breadcrumb       | Restore previous count |

## Copywriting Contract

All copy is exact — executors must use these strings verbatim.

| Element                       | Copy                                                                    |
|-------------------------------|-------------------------------------------------------------------------|
| File list empty state heading | `No SOPS files found`                                                   |
| File list empty state body    | `No .sops.yaml discovered in this directory or parents.` + newline + `Run sops-tui in a repository with a .sops.yaml configuration.` |
| Detail empty state            | `No keys found in this file`                                            |
| Unencrypted file banner       | `Not yet encrypted — matches .sops.yaml rules`                          |
| Metadata overlay title        | `SOPS Metadata`                                                         |
| Metadata overlay footer       | `Press i or Esc to close`                                               |
| Help overlay footer           | `Press ? or Esc to close` (established Phase 1 — do not change)        |
| Search empty results          | `No matches`                                                            |
| Search prompt glyph           | `/` (forward slash — k9s convention)                                    |
| `[unencrypted]` badge text    | `[unencrypted]`                                                         |
| `[plain]` badge text          | `[plain]`                                                               |

| Type hint: integer            | ` (int)` (leading space, parentheses, lowercase)                        |
