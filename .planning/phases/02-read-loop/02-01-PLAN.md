   ```go
   package sops

   // SopsConfig represents the top-level .sops.yaml structure.
   type SopsConfig struct {
       CreationRules []CreationRule `yaml:"creation_rules"`
   }

   // CreationRule represents a single creation_rule entry in .sops.yaml.
   type CreationRule struct {
       PathRegex        string `yaml:"path_regex"`
       EncryptedRegex   string `yaml:"encrypted_regex"`
       UnencryptedRegex string `yaml:"unencrypted_regex"`
       Age              string `yaml:"age"`
   }

   // DiscoveredFile represents a file matched by .sops.yaml rules.
   type DiscoveredFile struct {
       Name        string       // relative path from .sops.yaml directory
       AbsPath     string       // absolute path on disk
       IsEncrypted bool         // true if file contains top-level "sops:" key
       Rule        CreationRule // the first matching creation rule
   }

   // Discover parses the .sops.yaml at sopsYamlPath, walks the directory tree
   // rooted at its parent, and returns all files matching any creation_rule path_regex.
   // Each file is checked for a top-level "sops:" YAML key to determine IsEncrypted.
   // Uses first-match-wins rule ordering, consistent with SOPS behavior.
   func Discover(sopsYamlPath string) ([]DiscoveredFile, error)
   ```

   Implementation details:
   - Parse .sops.yaml using `goccy/go-yaml` Unmarshal into SopsConfig
   - Walk the directory tree using `filepath.WalkDir` from the .sops.yaml parent directory
   - Skip directories named `.git`, `.svn`, `node_modules`
   - For each regular file, compute `relPath, _ := filepath.Rel(sopsYamlDir, filePath)` then test against each rule's PathRegex using `regexp.Compile` (NOT MustCompile -- return error gracefully for invalid regex, skip the rule with continue)
   - Empty PathRegex matches all files (catch-all rule)
   - First matching rule wins -- stop checking further rules for that file
   - For matched files, call `hasSOPSMarker(absPath)` to determine IsEncrypted
   - Security: validate that every discovered file's absolute path starts with the sopsYamlDir prefix (prevent directory traversal via crafted path_regex). Use `filepath.Abs` + `strings.HasPrefix` check.

   Helper functions (unexported):
   - `func matchRule(filePath, sopsYamlDir string, rules []CreationRule) (CreationRule, bool)` -- returns first matching rule
   - `func hasSOPSMarker(absPath string) bool` -- reads file, unmarshals top-level keys only using `yaml.MapSlice` with `yaml.UseOrderedMap()`, checks for `"sops"` key

2. Create `internal/parser/yaml.go` with these exact types and functions:

   ```go
   package parser

   import (
       "fmt"
       "strings"

       yaml "github.com/goccy/go-yaml"

       "github.com/caesarakalaeii/sops-tui/internal/sops"
       "github.com/caesarakalaeii/sops-tui/internal/ui"
   )

   // SopsMetadata holds metadata extracted from the sops: block of an encrypted file.
   type SopsMetadata struct {
       Version          string
       LastModified     string
       MAC              string
       AgeRecipients    []string
       EncryptedRegex   string
       UnencryptedRegex string
   }

   // ParsedFile is the result of parsing a SOPS-encrypted YAML file.
   type ParsedFile struct {
       Nodes    []ui.TreeNode
       Metadata SopsMetadata
   }

   // ParseFile reads a YAML file at absPath and returns the tree structure and SOPS metadata.
   // The sops: top-level key is excluded from the tree (D-05) and extracted into Metadata.
   // Encrypted leaf values (starting with "ENC[") get Encrypted=true and TypeHint from the type: suffix.
   // The rule parameter determines which plain values get IsPlain=true based on encrypted_regex/unencrypted_regex.
   // If isEncrypted is false (file has no sops: block), all values are shown as plaintext.
   func ParseFile(absPath string, rule sops.CreationRule, isEncrypted bool) (ParsedFile, error)
   ```

   Implementation details:
   - Read file with `os.ReadFile(absPath)`
   - Add a 10MB file size guard: if len(data) > 10*1024*1024, return error "file too large (max 10MB)"
   - Unmarshal using `yaml.UnmarshalWithOptions(data, &root, yaml.UseOrderedMap())` where root is `yaml.MapSlice`
   - Walk top-level MapSlice: if `item.Key.(string) == "sops"`, extract metadata into SopsMetadata; skip from tree
   - For metadata extraction: re-marshal the sops value and unmarshal into a helper struct:
     ```go
     type sopsBlock struct {
         Version          string     `yaml:"version"`
         LastModified     string     `yaml:"lastmodified"`
         MAC              string     `yaml:"mac"`
         Age              []ageEntry `yaml:"age"`
         EncryptedRegex   string     `yaml:"encrypted_regex"`
         UnencryptedRegex string     `yaml:"unencrypted_regex"`
     }
     type ageEntry struct {
         Recipient string `yaml:"recipient"`
     }
     ```
   - Recursive `walkMapSlice(ms yaml.MapSlice, depth int, rule sops.CreationRule, isEncrypted bool) []ui.TreeNode` function
   - In `buildNode`: use type switch on `value` (NOT type assertion) per Pitfall 7:
     - `yaml.MapSlice` -> recurse as group node
     - `string` -> if `strings.HasPrefix(v, "ENC[")` -> encrypted leaf with `extractTypeHint(v)`; else -> check if plain via `isPlainValue(key, rule, isEncrypted)`
     - `int`, `int64`, `float64`, `bool` -> plaintext leaf with `fmt.Sprintf("%v", v)`, IsPlain=true if file is encrypted
     - `default` -> plaintext leaf with `fmt.Sprintf("%v", v)`
   
   - `func extractTypeHint(enc string) string`: find `",type:"` using `strings.LastIndex`, extract suffix before `"]"`, default to `"str"` if not found
   - `func isPlainValue(key string, rule sops.CreationRule, isEncrypted bool) bool`: returns true when:
     - File is encrypted AND rule has EncryptedRegex: key does NOT match encrypted_regex (value was left unencrypted)
     - File is encrypted AND rule has UnencryptedRegex: key DOES match unencrypted_regex
     - File is encrypted AND rule has neither regex: return false (all non-ENC values are anomalous)
     - File is NOT encrypted: return false (whole file is plaintext, no badge needed)

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Tampering | discoverer.go matchRule | mitigate | Use regexp.Compile (returns error) not MustCompile; skip malformed regex rules with continue |
| T-02-02 | Tampering | discoverer.go Discover | mitigate | Validate discovered file abs paths start with sopsYamlDir prefix via filepath.Abs + strings.HasPrefix; reject files outside repo root |
| T-02-03 | DoS | parser.go ParseFile | mitigate | File size guard: reject files > 10MB before parsing to prevent unbounded memory allocation |
| T-02-04 | Tampering | parser.go buildNode | mitigate | Use type switch on yaml values (not type assertion) to prevent panics on unexpected YAML types |
| T-02-05 | Information Disclosure | parser.go extractTypeHint | accept | ENC values are treated as opaque strings; type hint is metadata only, not secret content |
</threat_model>
