  <what-built>
Phase 5: Power Features — recipient management (view, add, remove), bulk re-key with per-file confirmation, and secret health checks (weak, duplicate, stale).

Key flows to verify:
1. **File Selection**: Space toggles [+] indicator on files in file list
2. **Add Recipient** (a in detail): Modal form validates age key, shows diff confirmation, calls sops rotate --add-age
3. **Remove Recipient** (d in detail): Numbered list of recipients, diff confirmation, calls sops rotate --rm-age
4. **Bulk Re-Key** (K in file list): Per-file confirmation overlay, status bar progress
5. **Health Check** (H in file list): Decrypt-all confirmation, scans for weak/duplicate/stale, full-screen results overlay
  </what-built>
  <how-to-verify>
Prerequisites: Ensure you have a test repository with `.sops.yaml` and at least 2-3 SOPS-encrypted YAML files with your age key configured.

**Test 1: File Selection (RCP-03)**
1. Run `go run ./cmd/sops-tui/`
2. In the file list, press `space` on a file
3. Verify: `[+]` appears before the filename
4. Press `space` again — `[+]` disappears
5. Select 2+ files with `space`

**Test 2: Bulk Re-Key (RCP-03)**
1. With files selected, press `K`
2. Verify: Confirmation overlay shows "Confirm Re-key: filename" with current recipients listed
3. Press `y` to confirm first file
4. Verify: Status bar shows "Re-keying 2/N: nextfile"
5. Press `n` to skip a file
6. Verify: When queue is empty, flash shows "Re-key done: N updated, M skipped"
7. Verify: All `[+]` selections are cleared

**Test 3: Add Recipient (RCP-02)**
1. Navigate to a file detail view (Enter on a file)
2. Press `a`
3. Verify: "Add Recipient" overlay appears with "Age public key:" label
4. Type an invalid key like "notakey" and press Enter
5. Verify: Inline error "Invalid age key: ..." appears
6. Press Esc, then press `a` again
7. Type a valid age public key and press Enter
8. Verify: Diff confirmation overlay shows the new key as "+" line
9. Press `y` to confirm (or `n` to cancel)
10. Verify: Flash shows "Recipient added. File re-encrypted." (or "Cancelled")

**Test 4: Remove Recipient (RCP-02)**
1. In detail view, press `d`
2. Verify: Numbered list of recipients appears
3. Press the number corresponding to a recipient
4. Verify: Diff confirmation shows the recipient as "-" line
5. Press `y` or `n`
6. Verify: Flash message confirms result

**Test 5: Health Check (HLT-03)**
1. Return to file list (Esc from detail)
2. Press `H`
3. Verify: Confirmation overlay asks to decrypt all files
4. Press `y`
5. Verify: Status bar shows "Decrypting all files for health scan..."
6. Verify: Health overlay appears with findings grouped by Weak/Duplicate/Stale
7. Press `j`/`k` to scroll through findings
8. Press `Esc` or `H` to close
9. Verify: Returns to file list

**Test 6: Esc Chain**
1. Open health overlay (H -> y) -- press Esc -- verify returns to file list
2. Open add recipient (a) -- press Esc -- verify returns to detail
3. Open remove recipient (d) -- press Esc -- verify returns to detail
4. Start bulk re-key (K) -- press Esc on confirmation -- verify file is skipped, next file shown
  </how-to-verify>
