  3. Return result (caller is responsible for clearing the input map after calling)

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| TUI input -> sops subprocess | User-provided age public key string crosses from TUI input to CLI argument |
| Decrypted values -> health checker | Plaintext secret values held in memory during health analysis |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-01 | Tampering | sops/executor.go AddRecipient | mitigate | Validate age public key with `age.ParseX25519Recipient()` before calling sops (delegated to Plan 02 RecipientFormModel per D-02) |
| T-05-02 | Information Disclosure | health/checker.go FindDuplicates | mitigate | Store only SHA-256 hashes in Duplicate.ValueHash, never plaintext values; caller must nil-out input map after calling FindDuplicates |
| T-05-03 | Denial of Service | sops/executor.go AddRecipient/RemoveRecipient | mitigate | SopsRotateTimeout = 60s prevents indefinite hang; exec.CommandContext cancels on timeout |
| T-05-04 | Information Disclosure | sops CLI args | accept | Age public keys are not secret — safe to pass as CLI args. Private keys never appear in args. |
</threat_model>
