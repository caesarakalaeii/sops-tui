**internal/ui/health.go:**
- Package: `package ui`
- Imports: `"fmt"`, `"strings"`, `"time"`, `"charm.land/lipgloss/v2"`, `"github.com/caesarakalaeii/sops-tui/internal/health"`
- Note: HealthModel has no `Update()` -- scrolling is driven by the parent AppModel, exactly as HistoryModel and MetadataModel work.

Struct:
```go
type HealthModel struct {
    results health.HealthCheckResult
    loading bool
    width   int
    height  int
    scroll  int
}
```

Constructor: `func NewHealthModel(width, height int) HealthModel` -- sets `loading: true`.

Methods:
- `func (m *HealthModel) SetResults(results health.HealthCheckResult)` -- sets results, sets `loading = false`
- `func (m *HealthModel) ScrollDown()` -- clamp at `len(lines)-1` where lines are from `buildContentLines()`
- `func (m *HealthModel) ScrollUp()` -- clamp at 0
- `func (m *HealthModel) SetSize(width, height int)` -- update dimensions
- `func (m HealthModel) View() string` -- render full-screen overlay

View rendering logic:
1. Title: `HealthSectionHeaderStyle.Render("Secret Health Check")`
2. If `m.loading`: show `DimText.Render("Running health check...")`; return bordered box
3. If `m.results.IsEmpty()` and `len(m.results.Errors) == 0`: show `"No issues found."` with `HelpSectionHeader.Render("All secrets passed health checks.")`
4. Otherwise, build sections:
   - If `len(m.results.WeakSecrets) > 0`: header `HealthSectionHeaderStyle.Render("Weak Secrets")` + each entry as `HealthWeakStyle.Render("[WEAK]") + "  " + filePath + " > " + keyPath + "  (" + reason + ")"`
   - If `len(m.results.Duplicates) > 0`: header `HealthSectionHeaderStyle.Render("Duplicates")` + each duplicate: `HealthDupeStyle.Render("[DUPE]") + "  " + loc1 + "  AND  " + loc2` (if >2 locations, join all with "  AND  ")
   - If `len(m.results.StaleFiles) > 0`: header `HealthSectionHeaderStyle.Render("Stale Files")` + each: `HealthStaleStyle.Render("[STALE]") + "  " + filePath + "  (last changed " + daysSince + " days ago)"`
5. Footer: errors line if `len(m.results.Errors) > 0`: `HealthSkippedStyle.Render(fmt.Sprintf("%d file(s) skipped -- could not decrypt", len(m.results.Errors)))`
6. Navigation hint: `DimText.Render("j/k scroll  H or Esc close")`
7. Apply scroll offset to content lines, render visible window
8. Full-screen bordered box: `lipgloss.NewStyle().Border(lipgloss.RoundedBorder()).BorderForeground(ColorMuted).Background(ColorSurface).Padding(1, SpaceMD).Width(m.width-2).Height(m.height-2).Render(inner)`

Helper: `func (m HealthModel) buildContentLines() []string` -- builds the full content as string slice for scroll calculation.

**internal/ui/recipientform.go:**
- Package: `package ui`
- Imports: `tea "charm.land/bubbletea/v2"`, `"charm.land/bubbles/v2/textinput"`, `"charm.land/lipgloss/v2"`, `"filippo.io/age"`
- D-01 substitution note: D-01 specifies "huh/v2" for the add-recipient modal form. This plan uses `bubbles/v2/textinput` wrapped in RecipientFormModel instead. Justification: (1) this is a single-field input that does not benefit from huh/v2's multi-field form handling, (2) the existing SearchModel in this codebase uses the identical textinput pattern and serves as a proven template, (3) huh/v2 is not in go.mod and would add dependency weight for no functional gain, (4) RESEARCH.md explicitly recommends this substitution (see "Don't Hand-Roll" table and Assumption A2). The modal form overlay UX specified by D-01 is fully preserved -- only the underlying widget library differs.

Struct:
```go
type RecipientFormModel struct {
    input     textinput.Model
    errMsg    string // validation error displayed below input
    width     int
    height    int
    confirmed bool
    cancelled bool
}
```

Constructor: `func NewRecipientFormModel(width, height int) RecipientFormModel`
- Create `textinput.New()` with `Placeholder = "age1..."`, `CharLimit = 200`, `Prompt = ""`
- Return with `width`, `height` set

Methods:
- `func (m *RecipientFormModel) Activate() tea.Cmd` -- reset confirmed/cancelled/errMsg, clear input value, return `m.input.Focus()`
- `func (m RecipientFormModel) IsActive() bool` -- returns `!m.confirmed && !m.cancelled`
- `func (m RecipientFormModel) Confirmed() bool`
- `func (m RecipientFormModel) Cancelled() bool`
- `func (m RecipientFormModel) Value() string` -- returns `m.input.Value()`
- `func (m *RecipientFormModel) SetSize(width, height int)`
- `func (m RecipientFormModel) Update(msg tea.Msg) (RecipientFormModel, tea.Cmd)`:
  - If `tea.KeyPressMsg`:
    - `"enter"`: validate with `age.ParseX25519Recipient(m.input.Value())`. If err != nil: `m.errMsg = "Invalid age key: " + err.Error()`, return. If valid: `m.confirmed = true`, return.
    - `"esc"`: `m.cancelled = true`, return.
  - Else: delegate to `m.input.Update(msg)`

- `func (m RecipientFormModel) View() string`:
  - Title: `DiffKeyStyle.Render("Add Recipient")`
  - Prompt label: `lipgloss.NewStyle().Foreground(ColorMuted).Render("Age public key:")`
  - Input area: `EditInputStyle.Width(m.width - 12).Render(m.input.View())`
  - Error line (if errMsg non-empty): `"\n" + ValidationErrorStyle.Render(m.errMsg)`
  - Footer: `ConfirmPromptStyle.Render("[enter]") + " confirm   " + ConfirmPromptStyle.Render("[esc]") + " cancel"`
  - Build inner from title + "\n\n" + prompt + " " + inputArea + errLine + "\n\n" + footer
  - Render in full-screen bordered box: `lipgloss.NewStyle().Border(lipgloss.RoundedBorder()).BorderForeground(ColorMuted).Background(ColorSurface).Padding(1, SpaceMD).Width(m.width-2).Height(m.height-2).Render(inner)`

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User text input -> age library validation | Untrusted string from textinput crosses to age.ParseX25519Recipient |
| User text input -> View rendering | Arbitrary text rendered in overlay -- no HTML/injection risk in terminal |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-05 | Tampering | recipientform.go input | mitigate | `age.ParseX25519Recipient()` validates bech32 encoding + 32-byte key before any sops call per D-02 |
| T-05-06 | Denial of Service | recipientform.go textinput | mitigate | `CharLimit = 200` on textinput prevents unbounded input; `age.ParseX25519Recipient` is O(n) on input length |
| T-05-07 | Information Disclosure | health.go View | accept | HealthModel displays file paths and key paths (not plaintext values) -- these are non-secret metadata visible in the filesystem |
