Create `internal/keys/bindings.go` in package `keys` with three KeyMap structs implementing `help.KeyMap` from `charm.land/bubbles/v2/help`:

**GlobalKeyMap** — keys available in every view (per D-09: global keys appear in every context):
- `Help`: key.NewBinding(key.WithKeys("?"), key.WithHelp("?", "toggle help"))
- `Quit`: key.NewBinding(key.WithKeys("q", "ctrl+c"), key.WithHelp("q", "quit"))

**FileListKeyMap** — keys for the file list view:
- `Up`: key.NewBinding(key.WithKeys("k", "up"), key.WithHelp("k/up", "move up"))
- `Down`: key.NewBinding(key.WithKeys("j", "down"), key.WithHelp("j/down", "move down"))
- `GoTop`: key.NewBinding(key.WithKeys("g"), key.WithHelp("g", "go to top"))
- `GoBottom`: key.NewBinding(key.WithKeys("G"), key.WithHelp("G", "go to bottom"))
- `HalfUp`: key.NewBinding(key.WithKeys("ctrl+u"), key.WithHelp("ctrl+u", "half page up"))
- `HalfDown`: key.NewBinding(key.WithKeys("ctrl+d"), key.WithHelp("ctrl+d", "half page down"))
- `Open`: key.NewBinding(key.WithKeys("enter", "l"), key.WithHelp("enter/l", "open"))
- Embed GlobalKeyMap fields (Help, Quit) so they appear in ShortHelp/FullHelp

**DetailKeyMap** — keys for the YAML tree detail view:
- Same Up, Down, GoTop, GoBottom, HalfUp, HalfDown as FileListKeyMap
- `Expand`: key.NewBinding(key.WithKeys("enter", "l", "right"), key.WithHelp("enter/l", "expand"))
- `Collapse`: key.NewBinding(key.WithKeys("h", "left"), key.WithHelp("h/left", "collapse"))
- `Back`: key.NewBinding(key.WithKeys("esc"), key.WithHelp("esc", "back to file list"))
- Embed GlobalKeyMap fields

Implement `ShortHelp() []key.Binding` and `FullHelp() [][]key.Binding` on both FileListKeyMap and DetailKeyMap. FullHelp groups: [navigation bindings], [action bindings], [global bindings]. Per D-09, this enables the help overlay to show contextual keybindings.

Export default instances: `DefaultGlobalKeyMap`, `DefaultFileListKeyMap`, `DefaultDetailKeyMap`.
