  ```go
  case tea.KeyPressMsg:
      switch {
      case key.Matches(msg, m.keys.GoTop):
          m.list.Select(0)
          return m, nil
      case key.Matches(msg, m.keys.GoBottom):
          m.list.Select(len(m.list.Items()) - 1)
          return m, nil
      case key.Matches(msg, m.keys.HalfUp):
          // Move cursor up by half the visible height
          idx := m.list.Index() - m.height/2
          if idx < 0 { idx = 0 }
          m.list.Select(idx)
          return m, nil
      case key.Matches(msg, m.keys.HalfDown):
          // Move cursor down by half the visible height
          idx := m.list.Index() + m.height/2
          max := len(m.list.Items()) - 1
          if idx > max { idx = max }
          m.list.Select(idx)
          return m, nil
      }
  ```
- Then delegate remaining messages (j/k/up/down, filtering, etc.) to `m.list.Update(msg)` — the list handles basic j/k/up/down navigation
- Return the updated model and command

type TreeNode struct {

Define a flat row representation for viewport rendering:

```go
type flatRow struct {
    node     *TreeNode
    depth    int
    isLast   bool    // last sibling at this depth (for └─ vs ├─)

}
```

Define `DetailModel`:

```go
type DetailModel struct {
    filename   string
    nodes      []TreeNode
    flatRows   []flatRow    // flattened visible rows (expanded nodes only)
    cursor     int           // index into flatRows
    scrollTop  int           // viewport scroll offset
    width      int
    height     int
    keys       keys.DetailKeyMap
}
```

Implement `NewDetailModel(filename string, nodes []TreeNode, width, height int) DetailModel`:

Implement `flattenNodes(nodes []TreeNode, depth int, parentIsLast []bool) []flatRow`:
- Recursive function that walks the tree

- Tracks depth and sibling position for connector rendering

Implement `Update(msg tea.Msg) (DetailModel, tea.Cmd)`:
- Handle `tea.KeyPressMsg` using `key.Matches(msg, m.keys.XYZ)`:
  - `m.keys.Up` (k/up): move cursor up (clamp at 0)
  - `m.keys.Down` (j/down): move cursor down (clamp at len(flatRows)-1)
  - `m.keys.GoTop` (g): cursor = 0
  - `m.keys.GoBottom` (G): cursor = len(flatRows)-1
  - `m.keys.HalfUp` (ctrl+u): cursor -= height/2 (clamp at 0)
  - `m.keys.HalfDown` (ctrl+d): cursor += height/2 (clamp at max)
  - `m.keys.Expand` (enter/l/right): if selected node has children and is collapsed, set Expanded=true, rebuild flatRows
  - `m.keys.Collapse` (h/left): if selected node has children and is expanded, set Expanded=false, rebuild flatRows
- Adjust scrollTop to keep cursor visible (scroll viewport)

  - Leaf nodes (no children):

  - Selected row: apply SelectedRow style (accent fg, surface bg) across full width
